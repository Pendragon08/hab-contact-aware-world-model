# 环境搭建记录（2026-09-10）

固定ManiSkill2 0.4.1/SAPIEN2.2.1；安装于自己的vendor_deps，不修改DMControl的运行环境。

安装后的原生仿真探测经历以下问题，均发生在正式训练之前：

- `cuda:1`渲染参数在CUDA_VISIBLE_DEVICES=1下报Cannot find cuda device suitable for rendering。
- `cuda:0`与`pci:65`探测的“仅出现GPU1进程”断言失败。进一步逐GPU检查进程类型/显存发现：PCI选择正确，但Vulkan枚举会额外建立GPU0的4MiB纯图形上下文；完整仿真渲染在GPU1占192MiB（C+G）。因此验证改为GPU1计算、GPU0只能有不超过8MiB图形上下文，而非掩盖或忽略占用。
- 第一次通过全部仿真断言后的报告写入失败：reports目录不存在。建立该目录后重新执行环境探测，报告已保存。这是报告目录问题，不是物理或学习过程故障。

完整环境探测结果：100决策/200原生步，重复种子轨迹最大差0.0，渲染384×640×3，原生dense奖励、pd_ee_delta_pos控制，原生成功判据正例true、反例false。人为放置物体用于验证判据，绝不计入策略成功率。

正式训练必须通过独立入口/优化器验证后启动；短验证通过不代表任务成功率达标。原HAB训练停止于426701已记录步骤，未伪造完成标记；日志及模型保留。GPU0的DMControl进程1789362持续运行，已核验其冻结源码哈希未改变。
