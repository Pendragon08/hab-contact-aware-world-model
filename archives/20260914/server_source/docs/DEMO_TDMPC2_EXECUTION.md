# 示范辅助 TD-MPC2 独立入口验证

环境沿用 `.aris/compute/ssh.md` 的 `d873b21f`；不安装依赖、不改变旧实验。服务器、只读解释器和资产路径由既有 `local-settings.sh` 提供。仅GPU1，GPU0至少12GiB空闲，数据盘至少15GiB剩余。

## 独立见证入口

从本地终端完整执行一次，不修复、不替换参数、不重跑：

```text
ssh -o BatchMode=yes -o ConnectTimeout=10 ouyanghao@10.147.17.32 "bash /data/code/ouyanghao/oyh/hab-contact-aware-world-model/scripts/run_demo_tdmpc2.sh witness"
```

预期最多600秒，退出0并打印 `DEMO_TDMPC2_WITNESS_PASS`。输出位于 `artifacts/demo_tdmpc2_v1/witness`；已有目录时拒绝覆盖。任何失败保留原日志和目录，交由主任务解释，见证者不要修改代码。

见证内容：10次离线更新且编码器/动力学/奖励/Q/策略参数均改变；原教师训练起点0的8步真实动作重放，初始环境/控制器/完整教师观测按已验证canonical规则配对、45维状态与奖励误差不超过1e-5；直接策略和MPC各8步真实控制；保存加载动作一致；最终一步TD目标无bootstrap且MPC不受超出回合末尾动作影响；一次在线混合回放更新通过。24个物理控制步，10次预训练更新、1次在线更新。没有性能达标主张，见证数据不进入正式训练。

## 正式入口

只有上述独立见证通过、配置哈希相同时才运行：

```text
ssh -o BatchMode=yes -o ConnectTimeout=10 ouyanghao@10.147.17.32 "screen -dmS demo_tdmpc2_v1 bash /data/code/ouyanghao/oyh/hab-contact-aware-world-model/scripts/run_demo_tdmpc2.sh run"
```

主任务启动后须核对screen进程、日志、GPU采样。最长8小时，失败不自动重启。执行中不得修改任何已快照脚本或配置。结果与更新日志在 `artifacts/demo_tdmpc2_v1/run`，进程日志在 `logs/demo_tdmpc2_v1_run.log`。

## 冻结训练协议

- 5M、45维输入、11维动作、128批量、3步模型窗口，保持固定版本网络。
- 5000次联合示范预训练：潜在一致性、真实奖励、记录行为的折扣有限回合回报Q监督；另用成功教师与训练起点纠错各半的128条动作监督训练潜在策略。运动10维均方误差与夹爪1维均方误差等权；标准差0.15的log-std正则系数0.01。
- 预训练结束后硬同步目标Q。在线30000真实控制步，每步1次联合更新，初始数据与已完成在线回合的窗口各64条；第一个在线回合结束前只有初始数据。在线策略使用原Q/熵目标＋系数1的示范/纠错动作约束，标准差正则不变。
- 200步有限回合：中途成功继续执行，第200步无价值bootstrap；剩余时长不足3步时MPC截断预测累计奖励且无回合外末端价值。原HAB奖励和成功条件不变。
- 在线起点轮转原80个fit起点，未接触20个dev起点。归一化仅来自已冻结20000训练状态，时间维不归一化。
- 0/10000/20000/30000步各保存完整检查点、分别对20个固定dev起点评估直接策略与MPC；每回合重新配对初始场景，保存视频、状态、动作、奖励、物理状态、成功条件和延迟。评估保存并恢复训练随机状态及MPC缓存，不进行优化。
- 每个检查点还在20条教师dev轨迹上核验1/2/3步奖励预测，对同一批窗口比较上一时刻奖励预测。窗口重叠，不作为独立统计样本。
- 全部检查点均报告，无开发结果选优。单任务单训练种子的工程开发实验，无最终benchmark结论。

尚无与本轮等预算的示范辅助SAC，因此当前配对只用于诊断同一TD-MPC2检查点中规划的作用。原版TD-MPC2及旧BC结果保留，不能把本扩展当成纯在线算法复现。
