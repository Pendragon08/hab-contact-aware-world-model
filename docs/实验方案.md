# 实验方案与进入条件

## 研究问题

在 ManiSkill-HAB 的 Fetch 抓取任务中，候选动作的接触后果预测是否能帮助机器人在完成任务的同时减少环境定义的累计触力超限？现阶段先检验简单控制的解释力，不能先假定世界模型必然提高性能。

## 第一阶段：冻结 SAC 的简单控制对照

`configs/contact_v1.json` 在新实验开始前固定。验证场景五布局各 20 个新种子、每方案 100 回合、每回合 200 步，总 60,000 步。

1. SAC 原动作，只使用官方固定头部设置。
2. 保守控制：运动通道先以 alpha=0.5 平滑，再乘 0.7。夹爪不变。
3. 力规则：相同平滑，缩放为 `clip(min(1, 50/max(f,ε), ((5000-C)/(201-t))/max(f,ε)), 0.2, 1)`，剩余累计预算负值截到零。f 和 C 来自当前动作执行之前上一步返回的信息，t 为即将执行的步号。夹爪不变。

三组改变的是运动指令，不是物理引擎、物体属性、原任务奖励或成功阈值。力规则有额外的模拟器力反馈，属于诊断对照；不是与原 SAC 完全等输入的学习算法比较。

主指标为曾经成功率与首次成功之前（若从未成功则整回合）的触力超限比例。结束成功率、全部时刻触力超限、完成步数、累计接触量和控制耗时为补充。成功条件为原始五条件合取。继续执行到 200 步，不对成功回合做物理冻结。

先用五布局的重复 SAC 验证新起点可复现，再在正式实验逐一比较初始模拟器与完整观测哈希。当前关节增量控制器导出的附加状态为空；控制器哈希相等本身不是额外状态恢复证据。没有验证任意中途恢复。

统计采用布局内分层配对 bootstrap，固定随机种子 91008、10,000 次。报告有利和不利变化、所有原始回合，不根据结果删回合。五布局属于同一宏观场景；不外推到独立房屋。

## 第二阶段：世界模型与匹配状态 SAC 的工程验证

`configs/state_pilot_v1.json` 固定：每算法 10,000 训练交互步，前 1,000 随机探索，之后每步一次梯度更新；200 步回合；batch 128。训练使用 train task plans，验证使用 val，验证数据不进入回放。

输入为 HAB 原生状态，再加入当前已返回的接触量、累计接触量和经过时间比例。动作去掉固定头部的两个维度，保留 11 个实际控制通道；两算法输入与控制空间相同。

TD-MPC2：5M 档隐式世界模型，隐状态维度 512，规划长度 3、512 个候选、64 个精英、24 条策略候选、6 次规划迭代。每次执行第一动作并重新规划。模型损失包括隐状态一致性、奖励和价值，策略从隐状态训练。

SAC：两个 256 宽隐藏层，双 Q、自动熵温度、gamma=0.975、tau=0.01、学习率 3e-4。使用相同状态与训练预算，网络参数数量不强制与 TD-MPC2 相同。它是独立实现的状态参考，不是官方 HAB 的大规模视觉 SAC 训练复现。

回放按完整回合保存，采样长度为 horizon+1 的状态窗和对齐的动作、奖励，不跨回合。固定时间截断按 continuing-task 设定自举，提前 success 标志不终止物理任务。

预检每算法 400 步训练和 400 步验证；正式 pilot 每算法 10,000 训练步与 4,000 验证步。预检轨迹不作为 pilot 初始化或训练数据。

验收分两层：工程验收要求参数真实更新、梯度/损失有限、检查点和全部轨迹可读、验证回合完整；科研验收需要足够训练后的任务成功能力和独立测试。本轮 pilot 仅能满足前一层，不能把短训未收敛解释为算法无效。

## 第三阶段：接触风险预测（有前置条件）

必须先建立可完成任务的世界模型基线，并锁定匹配输入的 SAC 对照、独立测试协议与训练预算，才进入风险模块训练和正式比较。短训成功率不足时，暂停风险模块扩展，优先处理探索和基线学习；不拿随机规划器去“证明”风险惩罚有效。

候选设计为：从当前隐状态、近期动作/接触历史和候选动作序列预测风险，MPC 中将任务价值与风险惩罚联合评分。风险监督只能来自训练轨迹。随机划分同一条轨迹的相邻时间窗会泄漏，须以场景/回合分割。

动作分支标签依赖真实可恢复的模拟器/控制器/观测堆叠/RNG 状态；在 HAB 上验证中途恢复之前，不执行虚假的分支标注。未经校准的 sigmoid 仅称风险分数，不能称准确失败概率。

完成上述条件后，才比较 TD-MPC2、TD-MPC2+规则、TD-MPC2+学习风险；再考虑扩展 Place 和组合技能。
