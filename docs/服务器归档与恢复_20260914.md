## 恢复

建议在 Linux 上恢复原服务器目录结构：

```bash
python scripts/restore_server_archive.py \
  --archive-dir tdmpc2-backup \
  --restore /data/code/ouyanghao/oyh/hab-contact-aware-world-model
```

目标目录必须不存在或为空，恢复脚本不会覆盖已有不同内容。先验证全部压缩分片，再逐文件恢复并核验内容。Linux 的动态库和符号链接应在 Linux 上使用。

本地尚未提交的修改另存于 `local_uncommitted_changes.zip`：其中 `tracked_changes.patch` 保存已跟踪文件的修改，`untracked/` 保存尚未跟踪的文件。请先比较内容后合并，不能直接假设它与服务器快照完全相同。
