# v0.2.0：接触控制配对实验与世界模型短训

本轮完成 ManiSkill-HAB Fetch Pick 的 300 个配对控制回合，以及 TD-MPC2 / 状态 SAC 各 10,000 步训练、9,000 次更新和 20 个验证回合。所有方案使用原始 HAB 成功条件，失败回合完整保留。

|方案|曾经成功|结束时成功|
|---|---:|---:|
|冻结官方 SAC|73/100|52/100|
|保守运动控制|75/100|67/100|
|接触力规则控制|63/100|56/100|
|TD-MPC2，10,000 步短训|0/20|0/20|
|状态 SAC，10,000 步短训|0/20|0/20|

保守控制相对官方 SAC 的曾成功率差为 +2 个百分点，配对区间为 [-5, +9]；力规则为 -10 个百分点，区间为 [-19, -2]。这不是完整 benchmark 或独立最终测试。状态策略短训尚未学会任务，风险预测模块尚未训练。

补充离线诊断：两种学习策略验证中均未出现抓住目标信号。对于奖励预测，上一奖励保持不变的因果参考在两种行为、三个预测步长上均比世界模型误差更低；优于训练均值不构成有效动力学或任务控制能力的证据。详细对照保存在仓库 `reports/world_model_prediction/时间序列参考诊断.md`。
