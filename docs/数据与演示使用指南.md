# 数据与演示使用指南

本页说明本轮 `v0.2.0-experiments` 发布后的使用方式。实验完成与发布状态以仓库 README 和 Release 的校验记录为准。

## 给老师展示

最快的方式是从 [实验 Release](https://github.com/Pendragon08/hab-contact-aware-world-model/releases/tag/v0.2.0-experiments) 下载 `comparison_demo.mp4`，用本地播放器打开。视频并排展示官方 SAC、保守运动控制和接触力规则控制；同一组使用相同初始条件，保持原播放速度。

演示包含按固定规则选取的成功和失败类型，选例记录在 `reports/contact_v1/example_selection.json`。不存在的类型会跳过；演示不能替代全部 100 组配对的统计。

需要查看任意回合时，下载并恢复下述归档，再打开仓库根目录的 `接触控制对比汇总.html`。页面包含完整 300 个回合视频，可暂停、拖动和全屏。它是离线网页，读取同目录下的本地视频；单独复制 HTML 到别处会使相对链接失效。

这些接触控制视频来自冻结的官方 SAC 及两种控制改动。短程训练的 TD-MPC2 / 状态 SAC 视频位于各自的 `state_*_pilot_v1` 目录，不能将官方 SAC 的抓取演示说成新训练世界模型的效果。

## 下载全部本轮数据

仓库当前为私有，需要有访问权限的 GitHub 账户。以下命令在克隆后的仓库根目录执行；视频播放与归档恢复不需要 GPU。

```bash
gh release download v0.2.0-experiments --repo Pendragon08/hab-contact-aware-world-model --dir release --skip-existing
python scripts/restore_artifacts.py --inventory release/contact-v1.release.json --root .
python scripts/restore_artifacts.py --inventory release/state-pilots-v1.release.json --root .
python scripts/restore_artifacts.py --inventory release/witnesses-v1.release.json --root .
python scripts/restore_artifacts.py --inventory release/run-records-v1.release.json --root .
```

归档恢复工具只依赖 Python 标准库，要求 Python 3.10 或以上。先验证压缩分片，再验证整包和逐文件 SHA256。已有文件内容一致时跳过，不一致时停止，保留现有内容；建议在新克隆中恢复。`--skip-existing` 只负责避免重复下载，真实性仍由后续校验确认。

|归档|内容|
|---|---|
|`contact-v1`|300 回合的状态、深度观测、动作、逐步指标、初始快照、完整视频和对比 Demo|
|`state-pilots-v1`|两算法的训练轨迹、更新日志、模型检查点、验证轨迹和 40 个验证视频|
|`witnesses-v1`|正式运行前的控制配对验证、短程训练验证及其视频|
|`run-records-v1`|日志、报告、图表、离线演示页面、运行时源码精确副本和审计记录|

历史 100 回合基线和更早的 Demo 位于 [v0.1.0-baseline](https://github.com/Pendragon08/hab-contact-aware-world-model/releases/tag/v0.1.0-baseline)，使用对应的 `legacy-layout100.release.json`、`hab-history.release.json` 恢复。两轮种子不同，不合并成同一配对实验。

## 读取一个配对回合

例如官方 SAC 的第 0 回合：

```python
import json
from pathlib import Path
import numpy as np

episode = Path("artifacts/contact_v1/sac/episode_000")
summary = json.loads((episode / "episode.json").read_text(encoding="utf-8"))
with np.load(episode / "trajectory.npz") as data:
    for key in data.files:
        print(key, data[key].shape, data[key].dtype)
    states = data["observed_states"]       # 第 0 帧至第 200 步，共 201 条
    raw_actions = data["actor_actions"]   # 冻结 SAC 给出的 200 个动作
    actions = data["executed_actions"]    # 控制改动后实际执行的 200 个动作
print(summary["success_once"], summary["success_at_end"])
```

同一编号下的 `sac`、`conservative`、`force_rule` 才是一组配对。种子和布局需同时核验，不能按不同目录中的任意成功回合配对。

`fetch_head_depth`、`fetch_hand_depth` 保存每步最新深度帧；完整初始三帧堆叠在 `initial_snapshot.pt` 中。重建策略输入的方法见 `scripts/audit_observation_replay.py`，不能把单帧直接当作三帧策略输入。

## 解释指标

- **曾经成功**：200 步中至少一步同时满足 HAB 的五项原始成功条件。
- **结束成功**：第 200 步仍同时满足五项条件。没有提前终止仿真。
- **成功前或未成功时触力超限**：成功回合检查截至首次成功的前缀；从未成功则检查完整回合。
- **奖励预测误差**：已训练 TD-MPC2 对保存验证轨迹的 1/2/3 步开环奖励预测 MAE / RMSE；不等于物体位姿或接触力预测精度。

五项成功条件为抓住目标、末端到达休止位置、机器人到达休止状态、满足静止条件、累计接触量未超限。累计接触量是环境定义的指标，不将其直接解释为物理冲量。

状态训练的 10,000 步结果用于判断训练入口和计算成本，尚不足以判断算法收敛。本轮没有训练风险预测模块；研究结论还需要充分训练、多种子、独立测试和消融实验。
