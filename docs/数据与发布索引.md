## 只看演示：无需 GPU

```bash
gh release download v0.5.1-metaworld-method-report \
  --repo Pendragon08/hab-contact-aware-world-model \
  --pattern '*.zip' --dir release/metaworld-demo --skip-existing
```

完整解压 ZIP 后，用浏览器打开其中的 HTML。不要只移动 HTML，否则可能找不到配套视频。当前算法与实验汇报的最新原稿位于仓库 `reports/`，首页提供对应 HTML；历史 Release 内容按其发布日期保留。

## 恢复带清单的历史原始数据

在仓库根目录执行，需 GitHub 仓库访问权限和 Python 3.10+。下面示例仅下载并恢复 v0.2 接触控制数据：

```bash
gh release download v0.2.0-experiments \
  --repo Pendragon08/hab-contact-aware-world-model \
  --pattern 'contact-v1*' --dir release --skip-existing
python scripts/restore_artifacts.py --inventory release/contact-v1.release.json --root .
```

工具检查分片及整包 SHA256、解压路径和逐文件校验；遇到已有不同内容文件会停止。演示 ZIP 和仅有 `training.npz` 的数据发布不使用这个清单恢复命令。更多归档映射见 [原始使用指南](数据与演示使用指南.md)；该指南只描述 v0.2 及其前序。
