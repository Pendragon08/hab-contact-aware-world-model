# 示范辅助 TD-MPC2：数据入口

这是 CPU 数据准备入口，**不会训练模型，不会访问 GPU**。训练入口尚未通过远端验证，不能将此文档当作训练启动说明。

## 执行

在仓库根目录、安装了 NumPy 的 Python 环境执行：

```text
python scripts/prepare_demo_tdmpc2.py
```

默认输出 `artifacts/demo_tdmpc2_v1/data`，已存在则拒绝覆盖。可用 `--output` 指向新的空目录独立重建。需要已还原 v0.3.0-bc-pilot 和 v0.3.1-bc-diagnosis 的原始轨迹。

输出 `training.npz` 和逐文件来源 `manifest.json`。程序检查原 BC 配置哈希、每条原轨迹哈希、80/20起点划分、索引/种子/任务一致性、动作执行通道、状态时间、力的时序、奖励总和及官方成功条件一致性。源文件只读。

## 数据语义

- 100 个200步回合：80个教师训练回合和20个学生训练回合，共20000个真实转移。
- `observations[e,t]`、`actions[e,t]`、`rewards[e,t]`、`observations[e,t+1]` 是同一个真实控制步的转移，窗口禁止跨回合。
- `actor_labels` 只用于动作监督。教师回合中等于执行动作；学生回合中是冻结教师的旁路建议，**没有对应的反事实下一状态**。
- `successful_teacher_episode` 选择53条教师结束成功回合（10600步）。`correction_episode` 选择20条学生回合（4000步）。其余教师失败回合依然进入世界模型学习。
- 没有读取开发集轨迹或开发集教师动作。100条教师的索引表仅用于核验80/20划分。
- 标准化统计仅从20000个训练的动作前状态计算，标准差下限0.001；时间维保持0到1。
- `terminal` 只在每个回合第200步为真。中途成功不结束回合。`monte_carlo_returns` 是折扣0.975的记录行为有限回合回报，不是最优Q值。
- 有限回合定义是本轮明确的算法适配；旧继续任务模型和结果不改写。训练时TD目标和规划时剩余时长必须共同遵循该定义。
