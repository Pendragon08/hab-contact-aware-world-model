## 4. 如何补充新结果

将配置、源码版本、步数口径、种子、评估协议和完成证据放入所属实验目录的 `reports/`；新运行保留独立目录。报告分别写最终检查点和中途最好值，分别统计曾成功与末步成功。视频注明检查点、种子和选例规则。大文件上传后更新 [发布索引](数据与发布索引.md)，最后更新首页的一行摘要。

历史报告与根目录 HTML 保留原路径，避免原有书签、脚本或视频相对路径失效。旧启动记录、时间戳方案和历史 README 仅用于追溯。
